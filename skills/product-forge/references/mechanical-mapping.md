# 机械映射、PRD 与原型

## 映射表

草稿有的 key，PRD 有同名小节；有代码则项目页面有对应区块，无代码则原型有对应可点区块。名称逐字相同，顺序与数组一致。仅当草稿出现该 key 时才用。术语以项目说明和本模块草稿为准。

| 草稿 | PRD | 项目（有代码） / 原型（无代码） |
|---|---|---|
| `用户` | 给谁用 | 权限与数据按此 |
| `场景` | 何时用 | 入口/壳与场景一致 |
| `需求` | 要做成哪件事 | 主路径只服务该需求 |
| `边界` | 不做 | 范围外的入口不出现 |
| `异常` | 页级异常怎么表现 | 可走到；失败页以草稿为准 |
| `端` / `入口` | 首行写端与入口 | 端决定壳；入口仅后台画面包屑 |
| `搜索` | 筛选项 | 筛选项 + 搜索 + 重置（按钮用草稿用词，缺则「搜索」「重置」）；枚举加「全部」 |
| `列表` | 列说明 + 空态 | 列顺序一致；后台默认分页 10 条/页，空单元格「—」 |
| `相关选项` | 枚举原样 | 选择器 / 徽章 / 单选，文案与顺序一致 |
| `操作` | 每条规则与可见条件；有成败按草稿 | 每条可点通；失败路径按草稿 |
| `步骤` | 逐步规则 | 步进或分屏，顺序一致 |
| 必填/可空/最长 | 校验 | 超出不可再输（草稿没写超限时） |
| `排序` | 列表排序 | 按该序 |
| `空` | 空态 | 空态可走到 |
| 详情 / 抽屉 / 弹窗 | 字段与校验 | 草稿写了用什么就用什么 |
| 其他模块 key | 同名小节 | 同名卡片/区块/屏幕 |

**默填**（草稿已有对应结构才补；不写进草稿）：最大条数写了、没写满额 → 满了禁用新增。

**演示切换**（仅无代码的 HTML 原型）：角落放「演示」，可切主路径，以及草稿里出现过的 `空` / 满额 / 失败 / `异常`。不写入草稿，不写入 PRD。有代码项目跟正式交互走。实现与原型只包含草稿已有的字段、按钮、状态、页面、步骤。

## 原型前调研

**仅无代码、要写 HTML 原型时必做。** 有代码项目时：对齐已有页面的 `:root`、密度与触控。只服务壳、密度、触控、信息层级；案例里多出来的模块、字段、按钮、步骤不进入草稿。

1. 按本页 `端` + 页面类型搜 2–4 个业内做得好的产品（现网或近一年评测）。
2. 各抽可复用的一点：布局骨架、触控尺寸、主路径焦点、空态/分享等同类交互的落点。
3. 合成进本页壳，仍遵守机械映射。
4. 完成回覆用一行写对标。

同项目已有模块 HTML 时（无代码路径）：先对齐已有 `:root`，再用案例补本页缺的密度与触控。只改视觉、结构同步时不必重做调研。

对标按 `端` 选（例如个人名片 H5 → Linktree 居中身份与整行点击、Read.cv 时间线叙事、HiHello 底栏分享）。

## PRD 与下游

`PRD.md` 是本页操作说明书。标题 = 模块名（加粗）。先四问，端与入口一行，此后小节 = 草稿其余 key 顺序。短句 + 列表，一条规则一行。项目说明已有术语直接用；本页新术语先写入草稿，必要时同步到项目说明。

**有代码**：改对应页面与接口，视觉跟已有项目走。

**无代码**时的原型：单文件 HTML，无构建、无 CDN、无框架。原生 JS，状态放内存。`lang="zh-CN"`；可聚焦控件有 `:focus-visible`。图标用清晰图形或文字，壳跟 `端` 走：

- 同项目已有其他模块 HTML → 复制其 `:root` 和通用 class，只加本页结构
- 管理后台 → 中后台密度（13px、表格、抽屉）；仅此时用面包屑和表格分页
- C 端 Web / H5 → 移动或内容站密度（大触控、单列；底栏/顶栏按草稿）
- App → 移动视口模拟
