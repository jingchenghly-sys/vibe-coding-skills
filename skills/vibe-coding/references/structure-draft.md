# 页面结构草稿

做某一页时，结构只写在业务项目的 `product/<页面名>/结构草稿.json`。页面名用该页的功能名。不写到 `web/`、`admin/`、项目根，也不只留在对话里。

这份 JSON 要能还原该页：有哪些块、什么顺序、每块里有什么、怎么点、空和失败时怎样。默认不写 `PRD.md`，不写 HTML 原型。用户明确要时再写，并且仍放在该页目录下。

项目级的用户、目标、场景、范围、主路径、端写在 `product/README.md`。本文件只约定这一页。

## 先写四问

先过及格线，再写本页结构。四问放在 `端` / `入口` 之前。

| 问 | key | 只回答 | 及格 | 不是 |
| --- | --- | --- | --- | --- |
| 用户 | `用户` | 谁用、什么角色 | 具体到角色 | 端名；「用户」一词 |
| 场景 | `场景` | 何时何地为何打开 | 有触发 | 交互步骤 |
| 需求 | `需求` | 这次要做成哪一件事 | 一件事 | 字段清单 |
| 边界 | `边界` | 本次范围外的事 | 「不做」能排除这类页的常见膨胀 | 字段长度、排序、空、成败；页级异常 |

`边界` 用短语或 `{"不做": "…"}`，并写清「不做」。没有页级异常就省略 `异常`。

## 再写这一页有什么

JSON。key 用业务名。数组顺序就是界面顺序。规则写成短语。有什么写什么，没有的 key 不补空壳。详情、弹窗、抽屉、步骤、区块各自成 key，内部用数组保序。字段约束写在对应 key 上。

| 有什么 | 必须写清 |
| --- | --- |
| 文本 / 输入 | 必填或可空；最大长度（或「不限」） |
| 列表 / 重复项 / 多图 | 排序；最大条数（或「不限」）；空时怎样 |
| 操作 | 成功怎样；失败怎样（是否保留已填）；何时不可用 |
| 可空区块 | 空时整块不出现，还是占位 |
| 选项 | 写入 `相关选项`：字段名 → 选项数组，顺序即展示顺序 |
| 页级异常 | 写入 `异常`（链接无效、无权限等）；没有则省略 |

另外写上：`端`、`入口`、谁可见、谁可操作、提交后的副作用、详情用抽屉 / 弹窗 / 新页。这些没说就按本页推断，写进对应 key。

页面形态看不清时，收成一次选择（列表、分步提交、设置表单），标明建议项。选定或按建议采用后写入。同一页不追问第二轮。推断进草稿的项，在文件末尾用 `本次推断` 列出。

## 按草稿还原页面

只出现草稿里有的字段、按钮、步骤和状态。名称与草稿逐字相同，顺序与数组一致。改页面先改这份草稿，再改 `web/` 或 `admin/`。

| 草稿 | 页面上 |
| --- | --- |
| `用户` | 谁能看、谁能操作、看到哪份数据 |
| `场景` | 入口和外壳与场景一致 |
| `需求` | 主路径只做这一件事 |
| `边界` | 范围外的入口不出现 |
| `异常` | 这些失败走得通，表现按草稿 |
| `端` / `入口` | `端` 决定壳。管理后台用面包屑，入口即面包屑；网页 / H5 用单列、大触控，不默认面包屑 |
| `搜索` | 筛选项，加上「搜索」「重置」；草稿另有按钮用词就用草稿的。枚举项前加「全部」 |
| `列表` | 列顺序一致。管理后台默认每页 10 条，空单元格用「—」 |
| `相关选项` | 选择器、徽章或单选，文案和顺序与数组一致 |
| `操作` | 每一条都能点通；成功、失败、不可用按草稿 |
| `步骤` | 步进或分屏，顺序一致 |
| 必填 / 可空 / 最长 | 超出不能继续输入 |
| `排序` | 列表按该顺序 |
| `空` | 空态走得通 |
| 详情 / 抽屉 / 弹窗 | 草稿写了哪种容器就用哪种，里面的字段和校验跟对应 key |
| 其他业务 key | 同名区块，内部顺序与数组一致 |

草稿写了最大条数、但没写满额时怎么表现：满了就禁用新增。这条不写进草稿。

## 示例

列表页。有搜索和表才用这些 key。

```json
{
  "用户": "运营；按权限看本页",
  "场景": "工作台里处理待办，要快速找到一条并处理",
  "需求": "按条件筛出列表，查看详情，必要时删除",
  "边界": "不做跨页批量",
  "异常": { "无权限": "不展示对应操作" },
  "端": "管理后台",
  "入口": "模块 → 页面",
  "搜索": ["字段A", "字段B"],
  "列表": ["字段A", "字段B", "操作"],
  "排序": "新到旧",
  "空": "表内提示暂无数据",
  "相关选项": { "字段B": ["选项1", "选项2"] },
  "操作": {
    "详情": "右侧抽屉",
    "删除": "弹窗确认，不可恢复；失败留在本页"
  }
}
```

分步提交页。按用户路径拆 key。

```json
{
  "用户": "已登录用户；游客只能预览",
  "场景": "首页点发布，要把一条内容发出去",
  "需求": "选类型、填内容、预览后提交，成功回信息流",
  "边界": "游客不展示发布",
  "端": "网页",
  "入口": "首页 → 发布",
  "步骤": ["选类型", "填内容", "预览", "提交"],
  "填内容": {
    "标题": "必填，最多30字",
    "正文": "可空，最多500字",
    "图片": "可空，最多9张"
  },
  "提交": {
    "成功": "回信息流并置顶本条",
    "失败": "留在本页，保留已填"
  }
}
```

设置页。

```json
{
  "用户": "运营",
  "场景": "设置里改本页展示开关",
  "需求": "打开或关闭配置并保存",
  "边界": "不做权限编辑",
  "端": "管理后台",
  "入口": "设置 → 本页",
  "展示": {
    "推荐位": "开关，默认开",
    "评论": "开关，默认开"
  },
  "操作": {
    "保存": "成功留在本页提示已保存；失败留在本页保留已改"
  }
}
```
