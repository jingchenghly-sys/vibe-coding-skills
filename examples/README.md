# examples

## 用法

1. 安装 `skills/vibe-coding` 到你的 Agent skills 目录（见根 README）。
2. 说：「按 vibe-coding 在 ~/workspace/projects/demo-app 生成项目骨架」。
3. 预期得到：

```text
~/workspace/projects/demo-app/
  .cursor/  server/  web/  admin/  product/  deploy/  README.md
```

栈为 Vue3+Ant Design Vue、Go Gin+GORM、Docker Compose。
